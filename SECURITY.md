# Segurança

Versão distribuída: 1.1.2.

Para relatar vulnerabilidades, utilize o recurso de reporte privado do GitHub se disponível. Caso contrário, solicite um canal privado sem publicar detalhes exploráveis, credenciais, cookies, exportações ou dados pessoais.

A triagem estática inicial não equivale a auditoria completa. A identificação integral de dependências continua pendente. Não há garantia de ausência de restrições de conta em plataformas de terceiros.
